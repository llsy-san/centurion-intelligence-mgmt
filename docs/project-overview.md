# 百夫长智能管理系统 - 项目概览

## 📋 项目简介

百夫长智能管理系统是一个基于微服务架构的现代化企业管理平台，集成了订单管理、支付处理、物流跟踪、AI智能分析等核心业务功能。

### 技术栈

| 层级 | 技术选型 |
|------|----------|
| **后端框架** | FastAPI + Python 3.11+ |
| **数据库** | PostgreSQL 15 + SQLAlchemy 2.0 |
| **缓存** | Redis 7 |
| **消息队列** | Celery + Redis |
| **文件存储** | MinIO / 阿里云OSS |
| **容器化** | Docker + Docker Compose |
| **API文档** | OpenAPI 3.0 + Swagger UI |

## 🎯 核心功能

### 业务功能
- **订单管理**: 订单创建、状态跟踪、订单查询
- **支付处理**: 多渠道支付、支付回调、退款处理
- **物流管理**: 物流跟踪、配送管理、库存管理
- **AI智能**: 智能推荐、数据分析、自动化决策
- **任务调度**: 定时任务、异步处理、批量操作

### 系统功能
- **API网关**: 统一入口、路由转发、限流熔断
- **文件服务**: 文件上传、下载、存储管理
- **用户认证**: JWT认证、权限控制
- **日志监控**: 结构化日志、性能监控

## 📊 服务详情

| 服务名称 | 端口 | 主要功能 | 技术特点 |
|----------|------|----------|----------|
| **API网关** | 8001 | 统一API入口、路由转发 | FastAPI、中间件、限流 |
| **订单服务** | 8002 | 订单CRUD、状态管理 | 异步处理、事务管理 |
| **支付服务** | 8003 | 支付处理、回调处理 | 第三方集成、安全加密 |
| **物流服务** | 8004 | 物流跟踪、库存管理 | 实时更新、状态同步 |
| **AI智能体** | 8005 | 智能分析、推荐算法 | OpenAI集成、机器学习 |
| **任务调度** | 8006 | 定时任务、异步队列 | Celery、分布式任务 |

## 🔧 开发规范

### 代码规范
- **Python**: PEP 8 代码风格
- **API设计**: RESTful API 设计原则
- **数据库**: 数据库设计规范和索引优化
- **错误处理**: 统一错误码和异常处理

### 项目结构
```
service-name/
├── app/
│   ├── __init__.py
│   ├── main.py              # FastAPI应用入口
│   ├── models.py            # 数据模型
│   ├── routers/             # API路由
│   │   ├── __init__.py
│   │   └── service_routes.py
│   ├── services/            # 业务逻辑
│   │   ├── __init__.py
│   │   └── service_logic.py
│   └── utils/               # 工具函数
├── tests/                   # 测试文件
├── docker/                  # Docker配置
├── Dockerfile
└── requirements.txt
```

### API设计规范
- **URL命名**: 使用复数名词，小写字母
- **HTTP方法**: GET(查询)、POST(创建)、PUT(更新)、DELETE(删除)
- **状态码**: 200(成功)、201(创建)、400(客户端错误)、500(服务器错误)
- **响应格式**: 统一JSON格式，包含code、message、data字段

## 🚀 快速开始

### 环境要求
- Docker 20.0+
- Docker Compose 2.0+
- Python 3.11+ (开发环境)
- 8GB+ 内存
- 10GB+ 磁盘空间

### 一键启动
```bash
# 克隆项目
git clone <repository-url>
cd centurion-intelligence-mgmt

# 快速启动
make start
# 或
./scripts/quick-start.sh
```

### 访问地址
- **API网关**: http://localhost:8001
- **API文档**: http://localhost:8001/docs
- **文件管理**: http://localhost:9001
